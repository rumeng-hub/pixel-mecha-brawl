# 像素机甲对战 · Pixel Mecha Brawl

> 单文件 HTML5 像素风 1v1 机甲格斗小游戏。零依赖，浏览器直接打开。

![Title](assets/title.png)

## 特性

- ⚙️ **两台机甲**：蓝色 P1 （Player） vs 红色 P2 （AI），Best-of-3 回合制
- 🗡️ **双攻击系统**：轻斩（快，低伤，远）+ 重斩（慢，高伤，近）
- 🛡️ **格挡反伤 & 完美格挡**：
  - 按住 `L` 格挡，护盾值耗尽前可减免伤害并**反伤 25%** 给攻击者
  - 抬盾 0.22 秒内的 **完美格挡（Parry）**：**反伤 55%**、打断对方硬直 0.6s、护盾 +25
- 🦘 **跳跃 + 空中攻击**：空中目标的高度会被感知；地面攻击打不到飞在空中的敌人，空中攻击可以俯冲命中地面目标
- 💨 **方向冲刺 + 空中冲刺**：冲刺方向由按住的方向键决定；空中限一次，冲刺期间短暂悬停无敌 0.16s
- 🤖 **AI 对手**：决策式 AI（接近 / 后退 / 防御 / 跳跃闪避 / 冲刺 / 攻击），难度中等
- 🎨 **纯程序化美术 & WebAudio 合成音效**：无外部素材依赖
- 📊 **HUD**：HP 条、护盾条、回合数、60s 倒计时、命中飘字、屏幕震动、粒子特效

## 操作表

| 操作 | Player 1 |
|---|---|
| 左移 / 右移 | `A` / `D` 或 `←` / `→` |
| 跳跃 | `W` / `↑` |
| 轻斩 | `J` / `Z` |
| 重斩 | `K` / `X` |
| 格挡（按住） | `L` / `C` |
| 冲刺 | `Space` / `Shift` + 方向键 |
| 开始 / 重开 | `Enter` / `R` |

### 战斗机制

```
HP          100    — 被打到清零即 KO
Guard       100    — 护盾；格挡中每秒流失 20；破防后会被击穿
Guard Drain 20/s   — 格挡时的消耗
Reflect     25%    — 普通格挡反伤比例
Parry Win   55%    — 完美格挡反伤比例（抬盾后 0.22s 内中招）
Parry Stun  0.6s   — 完美格挡时攻击者被打断的硬直
Jump V      172    — 起跳初速度 (px/s)
Gravity     420    — 空中重力 (px/s²)
Dash Speed  300    — 冲刺速度 (px/s)
Invuln      0.16s  — 冲刺无敌帧
Air Dash    1 / jump — 每跳限一次空中冲刺
```

## 玩法策略

- 先出轻斩试探：快、恢复短、能连续压制 AI
- 近身时突然重斩：伤害 16 但恢复长，被格挡要亏
- 观察对方抬盾！它刚按下的 0.22s 窗口是 **Parry 窗口**——你撞上去会被反杀 55% 血并被打断
- 跳起来可以躲掉地面攻击，但你在空中也会被空中攻击命中
- 冲刺 + 方向键可以从侧面绕到敌人背后

## 本地运行

两种方式都行：

```bash
# 方式一：起 HTTP 服务
cd pixel-mecha-brawl
python -m http.server 8080
# 浏览器打开 http://localhost:8080

# 方式二：直接双击
# 在资源管理器里双击 index.html 就能玩
```

## GitHub Pages 在线玩

仓库 → Settings → Pages → Source 选 `Deploy from a branch` → Branch `main` / `/ (root)` → Save

部署后访问 `https://<你的用户名>.github.io/pixel-mecha-brawl/`
